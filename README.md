# 🧵 HILOS — Sistema de Análisis Conspirativo

> *El motor cotidiano de verificación de amenazas y trazado de hilos rojos del Estado Profundo.*

**HILOS** es una aplicación web táctica e interactiva de análisis conspirativo de logotipos corporativos. El usuario puede seleccionar expedientes precargados o cargar cualquier imagen/capturar con cámara para trazar geometrías ocultas, vértices de anclaje y conexiones secretas mediante visión artificial multimodal.

---

## ⚡ Características

- 🎯 **Tablero de Corcho Interactivo**: Trazado animado de hilos rojos en SVG con barrido láser y efecto de sonido de pines al caer.
- 📐 **Capas Geométricas**: Filtrado en tiempo real por facción (*Masónica, Saturno, Reptiliana, Geometría Sagrada*).
- 📂 **Expedientes Forenses Expandibles**: Fichas desclasificadas con coordenadas relativas exactas y telemetría de contrainteligencia.
- 👁️ **Visión Multimodal en Tiempo Real**: Análisis de cualquier logo corporativo vía cámara o subida de archivo conectado a **Google Gemini 1.5 Flash Vision**.
- 📄 **Exportación de Informes PDF**: Generación client-side de informes clasificados completos listos para descargar con `jsPDF`.
- 🔊 **Audio Táctico Integrado**: Sintetizador procedural con Web Audio API (cero dependencias de audio externas).
- 🛡️ **Suite E2E Playwright**: 21 tests de interfaz, invarianza de layout y descarga validados.

---

## 🛠️ Stack Tecnológico

- **Frontend:** React 18 + Vite
- **Estilos:** Vanilla CSS / Tactical Dark Theme
- **Audio:** Web Audio API procedural
- **IA Multimodal:** Google Gemini 1.5 Flash Vision API
- **Documentos:** jsPDF
- **Testing:** Playwright E2E

---

## 🚀 Inicio Rápido

```bash
# 1. Instalar dependencias
pnpm install

# 2. Iniciar servidor de desarrollo
pnpm dev

# 3. Ejecutar suite de pruebas E2E
pnpm test:e2e

# 4. Compilar para producción
pnpm build
```
